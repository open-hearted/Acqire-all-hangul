# 学習理論: 四段連鎖モデル

記録日: 2026-07-16

## 概要

このアプリ（韓国語音素知覚訓練）の設計の背後にある仮説。知覚訓練と発話能力の関係を、能力の自動転移ではなく、意味理解と動機を経由した四段の時系列連鎖として捉える。

## 四段連鎖

1. **音素弁別**: 語彙的足場なしのIPA強制転写訓練により、日本語カテゴリに吸収されていた韓国語音が独立した知覚カテゴリとして分離する。커피/코피 が別の音として聞こえるようになる。
2. **意味理解**: 聞き分けられて初めて「ネイティブはこの対立を分けていた＝この音素対立は意味の細かさを担っていた」と気づく。弁別できない耳にはこの対立の存在自体が見えないため、この気づきは①の後にしか起こりえない。
3. **発話動機**: 「私もそれぐらい細かく言いたい」。②で意味的な細かさの存在を知ったことで、自分の表現もその解像度に上げたいという欲求が生まれる。
4. **発話弁別**: ③のドライブが調音行動に変換される。①で分離済みの知覚カテゴリが、調音のターゲットとセルフモニタリングの両方を提供するため、出し分けが実際に可能になる。

## モデルの要点

- 蝶番は②。知覚→発話の橋渡しをするのは意味の発見であり、能力の自動転移ではない。
- ②→③は認知から動機への変換、③→④は動機から調音行動への変換。
- ④の実行可能性は①が保証する（分離済みカテゴリがなければターゲットもセルフモニタも成立しない）。

## アプリとの対応

- このアプリが直接訓練するのは①のみ。
- 語彙学習を意図的に封印しているため、②は現在起こらない設計。これは①の測定データを汚染しないための意図的な凍結であると同時に、「①を完成させてから②を解禁した方が連鎖全体が速く回る」という訓練順序の主張でもある。
- 語彙解禁の瞬間に②が一気に起こる（分離済みの耳で単語を学ぶため、音素対立が最初から意味と結びつく）ことがこのモデルの予測。

## 測定指標と反証条件

- ①の指標: /regions の混同ペア率の低下、スロットあたり候補数（ブラケット依存）の縮小、カタカナメモとIPA転写の乖離の縮小。反証: 転写訓練を続けても混同ペア率が下がらない。
- ④の指標: 訓練前後の発話録音のフォルマント分析、ミニマルペア発話のネイティブ判定。反証: 知覚分離後も発話が改善しない。
- ②③の間接指標: 語彙解禁後、語形が正確な音韻詳細つきで記憶される（fuzzy lexical representations の回避）。反証: 語彙解禁後も曖昧な語彙表象のまま定着する。

## 関連する先行研究（部品レベル）

- Flege, Speech Learning Model: 発話の精度は知覚表象の精度に上限を規定される。
- Bradlow et al.: 日本語話者の英語 /r/-/l/ 知覚訓練のみで発話も改善した実証。本モデルでは「②③が実験中に暗黙に起きていた」と再解釈できる。
- 新規性は個々の部品ではなく、四段を明示的な時系列連鎖として配線し、「①のみを訓練し②を意図的に凍結する」訓練プロトコルに落とした点にある。
